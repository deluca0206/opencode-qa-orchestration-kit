# ADR-001 — Superseded custom backend: historical synopsis

Status: superseded. This English synopsis replaces the public historical ADR;
it is not the original verbatim record and does not rewrite past results.

## Historical direction

The initial design used a custom MCP browser backend and explored hooks,
namespace isolation and command quarantine. Later human direction retired that
backend in favor of the existing Fugazi-style Playwright CLI and native OAK-style
commands. Custom MCP, hooks, proxies, writers, sandboxes and quarantine are not
current kit capabilities.

Human approval enabled native `edit:*` for all five QA agents and cancelled the
separate writer. Restrictions on application writes and the engineer's three
test roots are behavioral rules, not filesystem confinement. Native commands
were restored despite the observed OpenCode 2.3.2 pre-model shell-interpolation
risk; only trusted human arguments are appropriate. Historical backend passes
must not be inherited as validation of the current CLI or native commands.

Current behavior and attribution are owned by [contracts.md](contracts.md),
[provenance.md](provenance.md) and [AGENTS.md](../AGENTS.md).
